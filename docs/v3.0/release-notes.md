# v3.0 リリースノート

v3.0 で**追加した機能**だけを、短く並べる。細かい挙動は、各機能の PR と文書を見る。

## 追加した機能

- **CLI(`pm`)**: ターミナルから人形使いを使う。`login` / `logout` / `whoami` で、ブラウザで承認してログインする(トークンは OS のキーチェーンに保存)。`tasks` / `task <ID>` で、自分に割り振られたタスクを、プロダクトをまたいで読める。単一バイナリを GitHub Releases に載せる仕組みも入れた。仕様は [cli.md](cli.md)
- **プロダクトの検索**: プロダクトの中で、メンバーなどを探して、そこへ移動できる
- **メモ(付箋)**: プロダクトの上にメモを置ける。公開・非公開を選べる。右クリック・長押しで、編集・削除・公開の切り替え。作成者だけが変更できる。公開に切り替えたら、ほかのメンバー全員にメールで知らせる
- **プロダクトのアイコン**: リーダーが、プロダクトに画像(png / jpeg / gif / webp、1MB まで)を設定できる。サイドバーの名前の左に出る。保存先は R2
- **プロダクトの設定**: サイドバーの行を右クリック・長押しして開く、大きなモーダル。名前の変更、アイコンの設定・削除、プロダクトの削除(赤で示す)をまとめた
- **メンバーのカードから「+ タスクを追加」**: カードの一番下の行から、そのメンバーを担当者にして追加できる
- **Jev による担当者の提案(api)**: タスクごとに担当候補の確率を出して、担当を付け替える API。**Jev の API キーが未取得のため、本物の Jev はまだ呼べない**。CLI の `assign` は未着手。仕様は [jev-assign.md](jev-assign.md)
- **404 ページ**と、**読み込み中の動き**

## 本番への反映

- DB: `products.avatar_key`、メモの作成者と公開・非公開の列を追加した(`migrate` で適用)
- R2 のバケット `ningyoutukai-product-avatar` を、api に `STORAGE` として付けた(公開 URL は `AVATAR_BASE_URL`)
