# v4.0 リリースノート

v4.0 で**追加した機能**だけを、短く並べる。細かい挙動は、各 PR と [overview.md](overview.md) を見る。

## 追加した機能

- **Markdown の文書**: プロダクトに、Markdown の文書を保存できる。長い説明を、タスクの説明に収めずに書ける
  - **ディレクトリ**: 文書は、ディレクトリに入れて整理する(1 階層)。画面の右側にツリーで出る(スマホは 1 ページ)
  - **読む・書く**: プレビューを見ながら編集できる。保存は「新しい版として残す」か「上書き」を選べる。前の版は履歴から読める
  - **同時編集はしない**: 編集中は、その文書にロックがかかり、編集している人の名前と緑の点が出る。30 分何も書かないと外れる
  - **権限**: ディレクトリごとに、メンバーへ「読み取り」「読み取りと書き込み」を、リーダーが付ける(何もなければ読み取りのみ)
  - **メールで知らせる**: 文書を変えたとき、その文書を渡されたメンバーに知らせる
  - **自動削除**: 長く呼び出されない文書は、自動で削除する(初期は 1 週間。プロダクトごとに変えられる。文書ごとに「削除しない」も選べる)。削除したら、参加者全員にメールで知らせる
- **タスクに文書を渡す**: タスクに、文書やディレクトリを渡せる。担当者は、タスクの詳細から読める
- **AI に任せる**: 担当者が、自分のタスクを AI(Claude Code など)に任せられる
  - **トークン**: 設定の「AI のトークン」で発行する。AI にできるのは、自分のタスクと渡された文書を読むことと、報告の下書きを保存することだけ
  - **`pm` CLI**: `pm tasks` / `pm context` / `pm doc` / `pm report` で、AI がタスクと文書を読み、報告を保存する
  - **報告の下書き**: AI の報告は、まず下書きになる。担当者が確認して、そのまま・直して報告に出すか、却下する。完了にするのは、人
  - **ツリーの AI のカード**: トークンごとにカードが出る。最近使われていれば緑の点と「動作中」。リーダーは動かせて、持ち主は取り消せる
- **画面の調整**: 設定に「一般」(アカウント情報)、背景の点をやめる、線の出る辺を位置で変える、コメントを拡大縮小に合わせるなど

## 本番への反映

- DB: 文書・ディレクトリ・権限・ロック、AI のトークン、報告の下書き、AI のカードの位置の表を追加した(`migrate` で適用)
- R2: 非公開のバケット `ningyoutukai-product-docs`(バインディング `DOCS`)を追加した
- 定期実行: 毎日 18:00 UTC(日本時間 3:00)に、自動削除が動く
