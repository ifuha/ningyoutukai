# v3.1 リリースノート

v3.1 で**追加した機能**だけを、短く並べる。細かい挙動は、各 PR と [overview.md](overview.md) を見る。

## 追加した機能

- **コメント**: 画面(ツリー)の好きな場所に、コメントを置ける。リーダーが、メンバーに伝えたいことを書くときに使う
  - **置き方**: ツールバーの「コメント」を押して、ツリーをクリックした位置に置く(Esc か、ほかのボタンでやめる)。入力欄は、Enter で送信、Esc でキャンセル
  - **見る**: プロダクトの参加者全員が見られる。ピンにホバーすると、作成者のアバターと名前、本文のカードが開く
  - **書く・直す**: 作成・編集・削除は、リーダーだけ。ピンをマウスで掴んで、位置を動かせる。編集・削除は、右クリック(スマホは長押し)か、カードの「…」のメニューから
  - **メールの通知**: コメントを書くと、メンバー権限の人にメールで知らせる(リーダーには送らない)
  - **メモとの違い**: メモは誰でも書ける個人の付箋。コメントは、リーダーがメンバーに知らせるためのもの

## 本番への反映

- DB: `product_comments` の表を追加した(`migrate` で適用)
- api: `GET` / `POST /api/product/:productId/comment`、`PATCH` / `DELETE /api/product/:productId/comment/:commentId`
